사진을 올리거나 기록을 남기려면 GitHub 개인 액세스 토큰이 한 번 필요해요. 이 토큰은 이 브라우저에만 저장되고, 다른 곳으로 전송되지 않아요.

  1. GitHub 토큰 발급 페이지로 이동 (로그인 필요)
  2. Repository access → Only select repositories → raphale 선택
  3. Permissions → Contents → Read and write로 설정
  4. 맨 아래 Generate token 클릭 후, 나오는 토큰 문자열을 복사
  5. 아래 입력창에 붙여넣고 저장
